# Duet

Read `README.md` first. It holds the vision in Sourish's words.

## Who and what

- Sourish is a designer building a free, open source desktop app for designers. He works on a Mac.
- Goal right now: UI mockups and a video presentation to show his audience, then build fast and ship fast.
- Hands-on design plus AI on one canvas. Options pop up as suggestions. Git in the backend.
- Free version cannot depend on paid API keys. The AI connects through tools the user already has, through a hidden terminal layer shown as chat and canvas options.
- Likely stack: Tauri desktop app. Not decided yet.

## Rules

- Talk in short messages. One idea per line.
- Plan in chat before creating or changing files. After the plan is agreed, work end to end.
- Research and lead sourcing go to Gemini, not here.
- Unsigned Mac app for now. Installation tutorials will cover it.
- Commits carry Sourish's identity only. No tool names or attribution lines.
