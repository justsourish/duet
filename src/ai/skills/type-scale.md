# Type scale
Text sizes that belong together.

- Use a small set of sizes: 12, 14, 16, 20, 24, 32, 48. Do not invent in-between sizes.
- Body text 16. Captions and labels 12 to 14. Section titles 20 to 24. Page titles 32 and up.
- Line height is about 1.3 times the size, which is how Duet draws text. Keep lines of text under about 70 characters wide.
- Show importance with size and weight together, not with colour alone.
- Do not use more than three different sizes on one screen.
