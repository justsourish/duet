# Friendly and modern
A friendly, modern interface with a soft off-white canvas, clean rounded cards, gentle tints, clear visual hierarchy, and purposeful colour.

## Core rules
- Page background is a soft off-white #f8f9fb.
- Cards are pure white #ffffff with 1px solid #eceef2 border and 14px corner radius.
- Hero balance card is white and large, with 1px solid #eceef2 border and 14px radius.
- Each transaction sits in its own separate card with 1px solid #eceef2 border and 14px radius.
- Each icon sits inside a soft tinted circle container (32x32px, radius 16px).
- Active navigation tab and links use vivid blue #2f6bed. Inactive nav items use #94a3b8.
- Text colours: money in uses #2e9e6b, money out uses #d6524a. Titles #0f172a, body #334155, muted #64748b.
- Typography uses a clean sans-serif: title 28px bold, row title 16px semi-bold, muted and secondary labels 13px regular.
- Spacing follows an 8px scale: 4, 8, 12, 16, 24, 32 px.
- Icons are 16x16 px with a thin outline stroke. Icons must be drawn as simple recognisable outline shapes made of circles, rounded rectangles and straight lines only (a profile icon is a circle head over a half-circle shoulders). Never draw a free curve for an icon.
- Mobile screens: 360px wide, bottom bar 56px tall, content margin 16px.

## Designer taste and hierarchy
- Every screen has ONE hero: the single thing the eye lands on first (the white hero balance card). The hero is bigger and has more weight than everything else: larger type (28px bold) and generous padding. Everything else is quieter.
- Colour carries meaning, never decoration: vivid blue #2f6bed for active states/links, #2e9e6b for money in, #d6524a for money out.
- Each transaction sits in its own card; do not collapse them into a single borderless list.
- Content never touches the edge of its container. Keep 16px padding inside every card and row, and make sure the longest text and number still fit with room to spare.
- Align every row to the same columns: icon, name and category on the left, amount right-aligned on the same right edge.
- Use empty space on purpose: let the list use the height or place the bottom bar right after the content.
